## Highlights

- **Color History is exact.** The newest tile is the colour you picked, and it
  appears when you release instead of lagging one pick behind.
- **"Record only while drawing" is back.** An optional History setting records a
  colour only when a canvas contact uses it, so picking in the wheel or with Alt
  does not add a tile.
- **Faster, clearer settings.** Browse for ICC profiles directly, search CSP
  shortcuts by pressing the shortcut, and copy/paste module settings as icons.

## Added

- **"Record only while drawing"** in History settings: a pick is only noted, and
  the next non-Alt canvas contact records the exact colour. Off by default.
- **Browse for ICC profiles** in the Session picker and Settings → Proof Color.
- **Search CSP shortcuts by pressing the shortcut**, with All / Commands / Tools &
  brushes filters and readable names.
- **Copy/paste module settings as icons**, plus an editable number beside every
  Module Size slider.
- **A simpler pastel app/tray icon**: a rounded square with one big `I`.

## Changed

- **The profile menu shows ten full rows and scrolls**, instead of squashing every
  ICC profile into the palette.
- **The Slider's out-of-gamut marking is per channel and has a hard edge**, and
  Hue nudges by one whole degree.
- **Auto-hide is instant**: the palette hides as soon as CSP loses focus, with no
  debounce or PowerShell re-query.
- **Settings reopens on the last tab used**, and the Modules tab is taller.
- **The Modules tab's light reflects visible instances** live, including instances
  hidden from the palette.

## Fixed

- **Color History no longer shows the previous pick.** Picks are recorded by main,
  and a left-button release over CSP commits the exact final colour at once.
- **History updates at the 100-colour cap**, so the grid no longer freezes on the
  previous head.
- **History no longer lags one pick behind while the palette is hidden.**
- **A pick delivered with an active-slot switch now enters History.**
- **Worktime pauses when you leave Clip Studio Paint again.**
- **Newly added or shown modules get their own column** instead of being appended
  under the last module.
- **CSP Shortcuts reads only the current workspace**, shows when it was saved, and
  has a Refresh button.
- **CSP commands show readable names**, and tool/subtool shortcuts are grouped.
- **Palette drags no longer switch Windows to Do Not Disturb.**
- **Auto-hide follows the foreground again**: a hotkey- or tray-shown palette hides
  when you leave CSP, unless Auto-hide is off.
- **Reconnect is quick and honest**, and the Session row says what the app is doing
  while disconnected.
- **The document profile picker can leave the palette and scroll**, and its Browse
  row actually applies the chosen file.
- **A module's preview shows even with no instance mounted.**
- **A snapped pair resizes as one**, and a non-primary palette shrinks to its
  content.
- **The module-settings popout survives being replaced**, and packaged builds
  unpack `foreground.ps1` so follow-focus works in the installed app.

## Removed

- **Ten selector modules were removed** because they were not ready for this
  release: Color Gamut, Color Wheel, Palette Tools, Picky Palette, Capture Color,
  Colour Constructor, Dither Calculator, Painting Study, Posterize / Dither and
  Value Checker.

## Install

Download `Iroiroppa.Setup.1.2.0.exe` (installer) or
`Iroiroppa-Portable-1.2.0.exe` (no install) from the assets below.

## Requirements

- Windows 10 or 11 (64-bit).
- Clip Studio Paint with Companion Mode (tested on CSP 5.0.4).

The builds are unsigned, so Windows SmartScreen may warn on first run
("More info" → "Run anyway").
