## Install

Download the installer (`Iroiroppa.Setup.<version>.exe`) or the portable build
(`Iroiroppa-Portable-<version>.exe`) from the assets below.

## Requirements

- Windows 10 or 11 (64-bit).
- Clip Studio Paint with Companion Mode (tested on CSP 5.0.4).

The builds are unsigned, so Windows SmartScreen may warn on first run
("More info" → "Run anyway").
