## Highlights

- **A multi-model color picker.** OKLab/OKLCH, OKHSV, OKHSL, CIELAB/CIELCH and
  HelmGen/HelmGen LCH are now views over one canonical color, with a Color Wheel,
  Color Slices, Color Slider and Color Disc.
- **Document-aware color proofing.** Set the document's color profile and the
  pickers work in its gamut, including wide-gamut RGB and CMYK profiles.
- **A more complete Settings window.** New About tab, What's New dialog, wider
  layout, profile dropdown in the Session row, and automatic update checks.
- **Quit & install / Replace & relaunch.** When a newer release exists, the footer
  downloads it and hands over to the installer or to a portable replacement helper.
- **A real shortcut system.** Toggle, hold or after-color-pick modes, per-palette
  keys, optional hiding after a Clip Studio Paint click, and configurable placement.
- **A new default palette.** Session, CSP Color, Color Wheel, Color Slices, Color
  Slider, Color History and Color Stat.

## Added

- Color Disc module.
- Color model families and a family filter in Appearance.
- About tab with version, build, links, author, credits, license and third-party
  notices available offline.
- What's New dialog on the first launch of a version.
- Auto update check, update download and install actions.
- Session color-profile dropdown.
- Project issue templates, pull request template, security policy and Dependabot
  configuration.
- A rewritten user guide with screenshots and a terminology guard in the tests.

## Changed

- Settings is 30% wider.
- Session shows the current profile in a dropdown; the connection detail is on the
  dot's tooltip.
- The default template and README screenshot use the new module order.
- User-facing text uses American spelling.
- The portable build replaces itself through a detached helper instead of asking
  the user to copy files.

## Fixed

- Color Disc no longer fades wide-gamut documents or lets the pointer leave the
  document gamut.
- Dropdowns and tooltips stay above Settings.
- The Disc, Wheel and Slices repaint consistently and keep the pointer on a valid
  color.
- The Windows installer closes a running copy before replacing files.

## Removed

- OKHWB model.
- The global crosshair setting; Color Slices has its own toggle.
- The separate sRGB gamut warning toggle.

## Internal

- Renderer i18n and Settings now render after the catalog loads.
- New tests for release notes, credits, update install helpers, terminology and the
  user guide.

## Install

Download `Iroiroppa.Setup.1.2.2.exe` (installer) or
`Iroiroppa-Portable-1.2.2.exe` (no install) from the assets below.

## Requirements

- Windows 10 or 11 (64-bit).
- Clip Studio Paint with Companion Mode (tested on CSP 5.0.4).

The builds are unsigned, so Windows SmartScreen may warn on first run
("More info" → "Run anyway").
