## Highlights

- **A quieter palette.** Redundant tooltips are gone: resize-edge and window-drag
  hints, Color History tile values, duplicate Color Stat readouts, CSP Color slot
  details, and CSP Shortcuts path/raw-command notes. Stateful and hidden-action
  hints remain.
- **A clearer user guide.** The guide now has one **Module List** page and a
  **Customize your palette** page, with screenshots kept to the page they explain.

## Changed

- Removed low-value tooltips from palette chrome, module chrome, CSP Color,
  Color Stat, Color History and CSP Shortcuts.
- Kept tooltips where they explain state or a hidden action: connection state,
  color profile, layout lock, palette and module menus, HEX copy/paste, CSP
  Shortcuts search and key recording, and the module settings/collapse buttons.
- Accessibility labels remain on controls whose visible tooltip was removed.

## Install

Download `Iroiroppa.Setup.1.2.3.exe` (installer) or
`Iroiroppa-Portable-1.2.3.exe` (no install) from the assets below.

## Requirements

- Windows 10 or 11 (64-bit).
- Clip Studio Paint with Companion Mode (tested on CSP 5.0.4).

The builds are unsigned, so Windows SmartScreen may warn on first run
("More info" → "Run anyway").
