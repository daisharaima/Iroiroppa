## Highlights

- **The installer no longer stops with "Iroiroppa cannot be closed."** It closes
  a running copy itself, so installing over an open palette just works.

## Fixed

- **Installing while Iroiroppa is open** no longer fails with "Iroiroppa cannot
  be closed". The installer now closes the running app before replacing files,
  including a copy started from another folder (such as the portable build).
- **A copy that really cannot be closed** (started by another Windows user, or
  as administrator) no longer traps the installer in a dialog that can never
  succeed; the install reports the file that is in use instead.

## Install

Download `Iroiroppa.Setup.1.2.1.exe` (installer) or
`Iroiroppa-Portable-1.2.1.exe` (no install) from the assets below.

## Requirements

- Windows 10 or 11 (64-bit).
- Clip Studio Paint with Companion Mode (tested on CSP 5.0.4).

The builds are unsigned, so Windows SmartScreen may warn on first run
("More info" → "Run anyway").
