# Pick a colour

Once it is connected, picking is the whole job: drag on a colour map, and the colour you are painting with in Clip Studio Paint follows.

## The everyday loop

1. In Clip Studio Paint, pick the brush, pencil or fill you want to use.
2. In Iroiroppa, press and drag inside a colour map — for example the big map in **Color Slices**, or anywhere on the **Color Wheel**.
3. Watch the Clip Studio Paint canvas while you drag: the colour changes live.

Let go when the colour is right. That is it.

## Where the colour lands

The **CSP Color** panel shows Clip Studio Paint's three colour slots:

- **Foreground** — the main drawing colour.
- **Background** — the secondary colour, used by the eraser-like tools and some fills.
- **Transparent** — the "no colour" slot.

Click a slot in that panel to choose which one your picks are written to. Painting normally uses the foreground, so that is where you will usually leave it.

## Live sync, and when to turn it off

By default Clip Studio Paint updates **while you drag**. On a heavy document that can feel sluggish, so **Settings ▸ General ▸ Live sync while dragging** can be switched off — then the colour is sent once, when you let go.

## Colours that come from Clip Studio Paint

The connection works both ways. Take the eyedropper in Clip Studio Paint and sample something, or use **Edit ▸ ...** colour changes in Clip Studio Paint, and Iroiroppa updates to match. The palette always shows the colour Clip Studio Paint is actually holding.

## Copying the numbers

**Color Stat** shows the current colour's hex code and channel values.

- Click the left half of the hex code to copy it.
- Click the right half to paste one in.
- Double-click it to type a hex code by hand.

## Reusing a colour

**Color History** lists colours you have picked recently. Click one to use it again.

## Shift keeps the lightness

While you drag, holding **Shift** keeps the current lightness and changes only the hue and strength. That is the quick way to try "the same colour, a bit more orange" without the whole panel getting lighter.

## Which map should I use?

- **Color Slices** — three separate maps, each a flat plane. Best for careful work and for understanding what is changing.
- **Color Wheel** — a hue ring with a shaped middle. Fastest for "a warmer version of this".
- **Color Slider** — three tidy sliders. Best for small adjustments.
- **Color Disc** — hue and strength on a circle, with a lightness bar underneath. Feels like a classic colour wheel.

They all control the same colour, so mix them freely. See [Colour pickers](Colour-pickers) for what each one does in detail.
