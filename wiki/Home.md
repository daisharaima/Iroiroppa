# Iroiroppa

Iroiroppa is a perceptually uniform color picker and a collection of helper tools for Clip Studio Paint on Windows. It floats above the canvas and sends the color you choose to Clip Studio Paint.

## Requirements

- Windows 10 or Windows 11, 64-bit.
- Clip Studio Paint with **Companion Mode** (the “Connect to smartphone” feature), on the same PC. Tested with Clip Studio Paint 5.0.4.
- Nothing is installed into Clip Studio Paint. Iroiroppa connects the same way the phone app does.

## Before you begin

Iroiroppa is an unofficial project, not affiliated with CELSYS. Companion Mode is undocumented and may change in a Clip Studio Paint update. The app is unsigned, so Windows may show a SmartScreen warning on first launch.
