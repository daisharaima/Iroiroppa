# Glossary

**Clip Studio Paint (CSP)** — the drawing program. Made by CELSYS.

**Companion Mode** — CSP's “Connect to smartphone” feature. Iroiroppa uses it to connect.

**Pairing** — the saved connection between Iroiroppa and CSP. **Forget pairing** removes it.

**Palette** — the floating window containing modules. More than one can be open.

**Module** — one panel in a palette: a picker, connection controls, history and so on. Modules can be moved, resized, hidden, duplicated and popped out.

**Float** — a module in its own window.

**Workspace** — a named saved arrangement of palettes and modules.

**Auto-hide** — show the palette while CSP is in front, hide it otherwise.

**Live sync** — send color changes while dragging instead of only on release.

**Color model** — a way of describing a color. Iroiroppa offers OKLCH, OKHSV, OKHSL, CIELAB, CIELCH, HelmGen and HelmGen LCH.

**OKLCH** — lightness (L), chroma (C) and hue (H). Used by the default Color Slices.

**OKLab** — the model Iroiroppa stores colors in internally.

**Chroma** — color strength; zero chroma is grey.

**Hue** — which color: red, orange, yellow, green and so on.

**Lightness** — how dark or light a color is.

**Gamut** — the range of colors a device or document can hold.

**Color profile** — a file describing what stored color numbers mean. **ICC profile** is the standard format.

**sRGB** — the common color space of the web and most screens.

**Adobe RGB** — a wider color space used in photography and print.

**CMYK** — the print color model: cyan, magenta, yellow and black.

**Proofing** — previewing a color through another profile without changing the document.

**HEX** — a color written as `#RRGGBB`. In Color Stat, HEX is the document's stored value; the separate sRGB row is the screen appearance.

**Transparent** — CSP's “no color” slot.

**Tray** — the Windows notification area near the clock.
