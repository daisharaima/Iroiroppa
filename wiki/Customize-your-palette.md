# Customize your palette

A palette is built from modules: small panels that each do one job.

## Move and resize

- Drag a module by its title bar.
- Drag its bottom edge to resize it.
- Click the chevron to minimize it. Session and Color Stat are already one line, so they have none.
- Use **Settings → Modules → Module size** for an exact height.

A module alone in a column fills it. Multiple modules split the column.

## Pop out a module

Drag a module's title bar off the palette to make it a separate window; drag it back to return. An empty window closes. If a window is off-screen, use **Bring floats back on screen** in the tray menu.

## Add, duplicate, hide or remove a module

![The Modules tab](images/settings-modules.png)

1. Open **Settings → Modules**.
2. Select a module in the left column.
3. Use its instance row:

| Control | Action |
| --- | --- |
| **＋** | Add another instance of the module. |
| **⧉** | Duplicate the selected instance. |
| Dot | **Green** is mounted; **grey** is hidden. Click to show or hide. |
| **✕** | Delete the instance. Click twice to confirm. |

Session and CSP Color are singletons and cannot be duplicated.

Deleted instance settings stay in **Trash** until you choose **Remove unused settings files**. A hidden instance is still mounted; it is only removed from the palette.

## Palette menu

Click **☰** in the palette's title bar.

| Item | Action |
| --- | --- |
| **Rename…** | Name the palette. |
| **Lock layout** | Prevent moving and resizing. |
| **Settings…** | Open Settings. |
| **Delete palette…** | Delete this palette, with confirmation. |

**Unsnap** appears when palettes are joined.

## Multiple palettes

- Drag a palette over another to merge them; a confirmation prevents accidental deletion.
- Drag a palette edge against another to snap them.
- **Settings → Layout** lists palettes and provides **Duplicate**, **Export** and **Delete**.
- **Import…** restores an exported palette.

## Workspaces

![The Layout tab](images/settings-layout.png)

**Settings → Layout** saves a named workspace and exports or imports the whole arrangement, including an old layout file.

Use workspaces for different setups: one for painting, one for color study, one for a second monitor. Switching a workspace replaces the current arrangement; export it first if you want to keep both.
